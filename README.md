# Yufeng (Parra) Wang — Robotics Portfolio

Personal academic portfolio for Yufeng Wang. Static HTML, CSS, and JavaScript, hosted on GitHub Pages.

## Local preview

From this repository, run `python -m http.server 8000` and open `http://localhost:8000`. No build step or package installation is required.

## Contents

- `index.html`: homepage
- `research/`: HAMR support-caster research and active spherical caster
- `projects/`: senior design, mechatronics, quadrotor autonomy, manipulation, and MEMS
- `assets/`: selected project photographs, original CAD screenshots, trajectory figures, eight recorded videos, public CV, and kinematics excerpt
- `styles.css`, `theme-init.js`, `script.js`: dark/light appearance, accessible optional motion, media interactions

The quadrotor project currently has no video; no illustrative reconstruction is included. The experimental trajectory figures are archived measurements and are not synchronized to the adjacent videos.

## Editing and publishing

Edit the corresponding HTML file, test links locally, then commit and push to `main`. Keep `.nojekyll` and the existing GitHub Pages settings. Preserve image captions and the distinction between completed results and ongoing work.
